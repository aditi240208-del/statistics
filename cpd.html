Module 1 · Manufacturing Quality Control

Normal Distribution

Industry problem: A factory machines steel shafts with a target diameter of 10 mm. If a shaft is too thin or too thick, it is defective. We need to predict what percentage of production will be defective, so we can set process controls.

Input parameters

Mathematical formulas

\[ f(x) = \frac{1}{\sigma\sqrt{2\pi}}\, e^{-\frac{(x-\mu)^2}{2\sigma^2}} \]
\[ P(a \le X \le b) = \Phi\!\left(\frac{b-\mu}{\sigma}\right) - \Phi\!\left(\frac{a-\mu}{\sigma}\right) \]

Results

Visualization

Validation: σ must be positive, and the lower limit must be less than the upper limit. The selected diameter x can be any value.
Module 2 · Cloud Request Inter-arrival Time

Exponential Distribution

Industry problem: A cloud server receives requests at an average rate of 12 per minute. We want to model the time between consecutive requests so we can size the server and plan for burst traffic.

Input parameters

Mathematical formulas

\[ f(t) = \lambda e^{-\lambda t}, \quad t \ge 0 \]
\[ P(T \le t) = 1 - e^{-\lambda t}, \qquad P(T > t) = e^{-\lambda t} \]
\[ P(T > t_2 \mid T > t_1) = e^{-\lambda (t_2 - t_1)} \]

Results

Visualization

P(T ≤ t) shaded Density curve
Memoryless property: The exponential distribution "forgets" the past. The probability that you wait at least another \(t_2 - t_1\) seconds, given you've already waited \(t_1\) seconds, is the same as the probability of waiting that long from the start. The server does not "remember" how long it has been idle.

Model assumption: This assumes a constant-rate Poisson arrival process — requests arrive independently at a steady average rate. Inter-arrival time is not the same as server response time; response time is how long the server takes to answer a request, which is a different quantity.
Module 3 · Warehouse Processing Time

Central Limit Theorem

Industry problem: A warehouse processes orders. The time to process a single order follows some arbitrary distribution (not necessarily normal). When we average many orders, the Central Limit Theorem guarantees the sample mean becomes approximately normal — letting us predict total processing time reliably.

Input parameters

Mathematical formulas

\[ \text{Mean of } \bar{X} = \mu, \qquad \text{Std error} = \frac{\sigma}{\sqrt{n}} \]
\[ \bar{X} \sim N\!\left(\mu,\; \frac{\sigma^2}{n}\right) \quad \text{for large } n \]

Results

Visualization — sampling distribution of the mean

Sampling distribution of \(\bar{X}\)
Key insight: As \(n\) grows, the distribution of the sample mean becomes more concentrated (narrower) around the population mean \(\mu\) — even if the underlying population is not normal. With \(n \ge 30\), the normal approximation is typically excellent.
